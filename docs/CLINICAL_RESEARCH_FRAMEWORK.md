# Clinical Research Framework

## Purpose

This document converts the project's clinical ambitions into a research-ready structure without presenting unperformed studies as completed evidence.

## Study-development sequence

```text
Research question
  → Intended use
  → Outcome definition
  → Protocol
  → Ethics / governance review
  → Recruitment
  → Data collection
  → Quality control
  → Statistical analysis
  → Report
```

## Example research questions

### Stroke

Does repeated use of the NeuroAdapt AI task environment improve predefined motor-performance outcomes compared with an appropriate comparator over the study period?

### Prosthetic adaptation

Does adaptive task practice improve predefined functional prosthetic-control outcomes or training adherence compared with a non-adaptive protocol?

### Usability

Can intended users complete core sessions with acceptable usability and comfort across the supported accessibility modes?

## Endpoint discipline

Primary endpoints must be specified before data analysis. Secondary/exploratory endpoints must be labeled accordingly.

The 30% improvement and 4-point VAS reduction appearing in the original project draft are planning hypotheses, not study findings.

## Participant safety

The research plan should define:

- inclusion/exclusion criteria;
- contraindications and screening;
- supervision model;
- stopping criteria;
- adverse-event reporting;
- device/sensor failure procedures;
- session interruption procedures;
- data withdrawal/deletion procedures where applicable.

## Research data package

A research release should include:

- versioned protocol;
- data dictionary;
- anonymization/pseudonymization scheme;
- code/model version;
- pre-specified analysis plan;
- quality-control checks;
- reproducible result generation.

## Regulatory positioning

The project must determine, with qualified regulatory/clinical counsel and based on the intended claims and jurisdictions, whether the software constitutes or supports a medical device and what regulatory pathway applies. No repository statement should imply certification before that determination and required evidence exist.
