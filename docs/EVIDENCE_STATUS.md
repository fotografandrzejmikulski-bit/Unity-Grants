# Evidence Status

This register is the source of truth for external claims.

| Claim / capability | Status | Required evidence | External-claim rule |
|---|---|---|---|
| Unity RT3D implementation | Planned | Runnable Unity build | Do not state as implemented yet |
| XR rehabilitation interaction | Architecture | Vertical-slice video/build | State as development target |
| EMG integration | Planned | Working adapter + test report | Do not state as integrated |
| Hand tracking | Planned | Device-specific demo | Do not state as validated |
| A.U.R.A. | Design specified | Prototype + benchmark | Describe as proposed system |
| ML/RL personalization | Future | Evaluation dataset + reproducible experiment | Do not claim clinical value |
| Predictive recovery model | Future | Validated model and prospective evaluation | Do not claim predictive accuracy |
| Phantom-limb pain benefit | Hypothesis | Controlled clinical evidence | Do not claim treatment efficacy |
| Stroke motor benefit | Hypothesis | Approved study + analysis | Do not claim efficacy |
| 100-patient pilot | Planned | Recruitment, protocol, dataset/report | Do not describe as completed |
| 50-clinic Global South deployment | Planned | Signed partners + deployment logs | Do not describe as achieved |
| Medical certification | Not established | Regulatory determination + evidence | Never imply certification |
| HIPAA/GDPR compliance | Not established | Jurisdiction-specific legal/security assessment | Avoid blanket compliance claim |
| Nonprofit applicant | Verify | Legal entity documentation | Must be confirmed before submission |
| Strategic partners / LOIs | Verify | Signed/dated documents | Do not imply partnership without them |

## Claim lifecycle

```text
Idea → Designed → Prototyped → Tested → Validated → Deployed
```

Every external statement should use the strongest status actually supported by evidence.

## Repository rule

A new claim should not be added to the README, pitch deck, or grant application without either a linked repository artifact or a clearly identified external source.
