# Roadmap

## Phase 0 — Foundation

**Goal:** establish a truthful, reproducible repository and project definition.

Deliverables:

- repository architecture;
- product specification;
- A.U.R.A. baseline specification;
- impact/KPI framework;
- accessibility requirements;
- research and privacy frameworks;
- risk register.

## Phase 1 — Unity vertical slice

**Goal:** demonstrate the central interaction in a real Unity build.

Deliverables:

- one rehabilitation environment;
- one task;
- one complete session loop;
- pause/exit safety controls;
- configurable difficulty;
- local session metrics;
- basic accessibility modes.

## Phase 2 — Adaptive prototype

**Goal:** demonstrate A.U.R.A. without making unsupported clinical claims.

Deliverables:

- deterministic adaptation policy;
- policy logging;
- synthetic-data test suite;
- bounded parameter changes;
- fallback behavior;
- reproducible benchmark against fixed difficulty.

## Phase 3 — Sensor integration

**Goal:** integrate external interaction/sensor streams through a stable abstraction layer.

Deliverables:

- input interface;
- sensor adapter contract;
- connection/disconnection state machine;
- calibration flow;
- data-quality checks;
- simulated sensor for development.

## Phase 4 — Usability and accessibility validation

**Goal:** test the application with representative users and iterate through documented co-design cycles.

Deliverables:

- participant-informed test protocol;
- accessibility acceptance tests;
- usability findings;
- issue log;
- release candidate.

## Phase 5 — Research pilot readiness

**Goal:** prepare evidence collection under appropriate clinical/research governance.

Deliverables:

- protocol draft;
- endpoint definitions;
- statistical analysis plan;
- data dictionary;
- privacy/security review;
- governance/ethics documentation as required.

## Phase 6 — Validation and scale

Only after appropriate evidence and regulatory assessment should the project move toward broader clinical deployment, institutional partnerships, or global distribution.
