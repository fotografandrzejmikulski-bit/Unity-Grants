# Prototype

This directory is reserved for the executable Unity prototype.

## Required vertical slice

The first demonstrator should prove one complete therapeutic interaction rather than attempting the entire product.

### Scenario

A user enters a calm RT3D environment, completes a guided reaching/grasping task, receives immediate visual/audio feedback, and finishes a short session.

### Required proof points

- Unity scene loads reliably;
- user can start and stop the task;
- movement input is normalized through the interaction abstraction;
- target/task parameters can be changed;
- A.U.R.A. baseline can modify one bounded difficulty variable;
- session metrics are recorded locally;
- loss of optional sensor input does not create a false success state;
- accessibility mode can be changed before or during a session where safe.

## Development rule

Do not add fabricated screenshots, benchmark numbers, patient results, partner logos, or claims of medical validation. Every visual or measurement used in a grant deck must be traceable to a real build, test, or source.
